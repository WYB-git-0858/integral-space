# 积分空间

多重积分的二维与三维实验室。纯静态站点，依赖随站点提供，不需要 API key。首页为三维实验室，`plane.html` 为二维实验室；顶部导航可互相切换。

启动：在此目录执行 `npm start`，打开 http://127.0.0.1:5173 。也可以用任意静态服务器托管 `dist`；模块与 Worker 需要 HTTP，不能直接双击 HTML。

- 23 个预设曲面/区域，有预先生成的三维缩略图；图鉴支持载入与叠加。
- 显式函数、隐式方程、单个不等式；支持省略乘号。每行一个边界。
- 安全算术解析器，不使用 eval；支持 sqrt、sin、cos、tan、asin、acos、atan、abs、exp、ln、log、log10、min、max、pow、floor、ceil。角度为弧度。
- 字母参数自动生成滑块。曲面各自设置颜色、透明度与内部方向。
- 自定义方程默认自动识别围成的有界区域；按符号和空间连通性分开检测，排除接触绘图边界的开放区域。手动不等式仍可指定内部。
- 多个围成区域可分别查看。隐藏的曲面与空白输入框不参与计算。
- 立体填充、单独显示、坐标视角、旋转、缩放、平移、自动旋转、PNG 导出。
- 每次打开显示空白坐标系，添加曲面只增加空白输入框。编辑保存到当前浏览器 localStorage，可主动点击“恢复上次编辑”，不会自动灌入默认函数或旧公式。

立体边界采用四面体内各约束的逐面几何裁剪，再按具有面积的公共面连接空间分量，不再用网格中心是否落在内部来裁掉渐薄区域。网格局部聚焦于立体范围，并保留坐标零平面作为网格节点；边界使用各原方程的梯度提供平滑法向，交线处保留棱角。体积通过裁剪后的多面体计算，仍为网格几何近似，不是解析结果或带误差保证的积分。

是否有界依然依据当前分片线性几何判断，并非一般数学证明。自动模式最多展示 12 个最大的有界分量。间断函数、奇点或缺乏任何采样特征的极小结构可能需要额外处理。测试覆盖默认范围中的原点渐薄边界、缩小至 0.1 和 0.01 的同类立体、网格闭合性和靠近原点的上下表面射线。

回归示例：`x+y+z=2`、`z=xy`、`z=0`。其第一卦限有界区域与第三卦限开放区域拥有相同的不等式方向，必须按连通分量区分，不能仅凭符号方向决定是否显示。测试覆盖此输入、两个不相连球体、开放曲面、空白输入框以及手动约束。

预览生成：`npm run previews`；解析、预设、边界和解析体积对照检查：`npm test`。

渲染：Three.js 0.180.0，MIT License 见 dist/vendor/LICENSE。

新增二维实验室：20 个预先绘制的曲线/区域模型，显式与隐式曲线、参数滑块、多曲线组合、独立线色和区域填色、围成区域单独显示、多个连通区域选择、面积估计、等比例坐标的平移缩放与 PNG 导出。二维填色采用三角形内逐约束裁剪和连通分量检测，保留原点节点，先粗识别再局部细化；曲线也在识别区域附近增加采样。圆环截线保留两段内部区间。刷新或重新进入从空白开始，分别保存，可主动恢复；同一次使用中切换实验室自动保留各自内容。

两套实验室共用本地 MathLive 0.111.1 数学编辑器，支持排版分式、根号、括号、次方和数学键盘；文本模式仍可用于直接输入和查看解析位置提示。库与字体随站点提供，许可证在 dist/vendor/mathlive/LICENSE.txt。

三维增加 x/y/z 动态截面、带孔截面填充与可选剖切，xy/xz/yz 坐标投影，边界交线与关键点、点击坐标检查，所选立体适配、正交/透视相机。二维增加竖直/水平截线、坐标轴投影与积分换序。解析积分限提示覆盖典型模型和可识别的显式上下界；任意隐式输入显示真实内部约束和数值截面，不伪称通用符号求解。所有面积、体积、截面与交点仍为数值近似。

新增检查：`node scripts/verify-labs.mjs`，覆盖 20 个二维预设、解析面积对照、原点与 0.01 尺度区域、圆环分段截线、分离区域、三维交线和截面。二维预览生成：`node scripts/make-plane-previews.mjs`。

计算优化：二维、三维均复用 Worker，最多保留一个当前任务和一个最新待算任务，丢弃过时的中间参数状态。未变化的图像直接跳过重算；Worker 的有界 LRU 缓存复用曲面采样、立体及区域结果，换色不影响几何，重新载入相同模型会重映射当前公式 ID。三维先以相同采样精度显示曲面，再计算立体；交线分析在 Worker 内完成。二维避免没有收益的第二轮细化，但小尺度区域仍保留必要细化；填色缓存边界路径（含孔洞），平移缩放不再逐帧重建全部三角形，绘制合并到动画帧。

三维积分面板提供直角/柱/球坐标切换，各有六种积分次序，显示换元、体积微元、雅可比因子、转换后的真实约束以及体积/一般函数两种积分形式。球坐标约定 φ 从 +z 轴量起，θ 为方位角。典型模型提供经过解析体积对照的嵌套积分限；未支持的组合或次序显示换元约束与 Ω′，不假定角度必为整周或伪造通用解析积分限。原公式含 r、rho、theta、phi 参数时，对应坐标变量自动加下标，避免与参数混淆。

`node scripts/verify-speed-coordinates.mjs` 检查 Worker 合并任务、缓存隔离与 ID 重映射、孔洞轮廓、换元数值一致性、雅可比数值行列式，以及柱/球坐标下 14 组解析体积对照和用户三曲面示例的柱坐标积分。性能样本记录在忽略的 artifacts/；单次本机测量不能代表所有设备或模型的加速。

本次工作区：顶部切换二维/三维会保留公式、参数、范围、样式、所选区域、分析选项和视角，撤销历史也各自保留。刷新或重新进入开启新的空白会话，localStorage 中的“恢复上次编辑”仍为主动恢复，两者独立。撤销/重做记录最多 60 步，连续输入与滑块拖动合并为一组；支持 Ctrl/⌘+Z、Ctrl/⌘+Shift+Z 以及 Ctrl+Y。

二维、三维均提供 Python 导出（.py），只导出已完成的当前计算，未完成或公式出错时提示等待/修正。文件含公式和可调用的 NumPy 函数、参数、范围、颜色及绘图网格快照；由 NumPy 和 Matplotlib 直接运行，不依赖本站或额外网格库。三维用 Poly3DCollection，二维优先用闭合轮廓填充，必要时回退到裁剪区域三角形，保留孔洞与独立区域。快照不会在修改 Python 公式后自动重新求网格，需要在网站重新生成后导出。可运行 `python integral_space_3d.py --save graph.png --no-show` 导出图片。

`node scripts/verify-workspaces-python.mjs` 检查会话切换/刷新隔离、分组撤销重做、编辑分支、NumPy 公式数值等价、导出文件实际运行与圆环/三曲面填充。该测试需本地 Python、NumPy、Matplotlib。
